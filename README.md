# 轻剪 EasyCut

> 一个**零安装、可离线**的本地视频剪辑小工具。用浏览器界面编辑，调用你电脑本机的 ffmpeg 导出。
> 适合给视频加中文说明、做画中画、变速、简单的多轨剪辑与拼接 —— 全部在本机运行，不上传、不联网。

本文档即**使用说明**。第一次用请从下面「快速开始」读起。

## 它能做什么
- **中文说明文字**：在画面任意位置加字，调字号 / 颜色 / 对齐 / 描边 / 半透明底框，并可设定**出现 / 消失时间**。
- **多轨道合成**：多条视频轨 + 文字轨，上层盖下层；可做**画中画 / 小窗 / 角标**。
- **变速**：单个片段慢放 / 快放（0.25×–4×），声音保持音调不变。
- **剪辑**：裁剪、分割、删除、波纹删除、复制 / 粘贴、拖动重排、跨轨移动、磁吸对齐。
- **拖拽导入**：从资源管理器把 mp4 拖进窗口；拖到素材库或直接拖到轨道。
- **实时预览** + **一键导出** 为新的 mp4（H.264 + AAC）。

## 运行环境
- **Windows 10/11**
- **Python 3**（用于本地服务，纯标准库，无需 pip 安装任何东西）
- **ffmpeg / ffprobe**（导出与解析视频；需可在命令行调用，或装在 WinGet 默认目录，程序会自动查找）
- 一个现代浏览器（Edge / Chrome 等）

> 不需要联网，不需要安装额外依赖。前端是纯原生网页，后端是一个 Python 小服务。

## 快速开始
1. **双击 `启动.bat`** —— 会弹出一个黑色命令行窗口，并自动打开浏览器进入编辑界面。
2. **使用期间请勿关闭那个黑色窗口**：它就是后台服务，关掉它工具就停了。
3. 用完后**直接关闭黑色窗口**即可停止。
4. 地址固定在 `http://127.0.0.1:8765`（端口被占用会自动换，以黑窗里显示的网址为准）。浏览器没自动开就手动访问该网址。

> ⚠️ 如果点「导入」没反应、或页面打不开，多半是**后台服务没在运行**（黑窗被关了）。重新双击 `启动.bat` 即可。

## 基本流程（最短路径）
1. **导入** mp4 → 进素材库
2. 从素材库**拖**一段到下方某条轨道
3. **编辑**：剪切、加文字、做画中画、调速度
4. **预览**：按空格播放
5. **导出**：点右上「导出」，选保存位置

---

## 一、导入视频（两种方式）
| 方式 | 操作 | 特点 |
|------|------|------|
| **拖拽导入** | 从资源管理器把 mp4 拖进窗口 | 方便；会把文件**复制**一份到工作目录，大文件稍慢 |
| **选择导入** | 点工具栏「导入 mp4」或素材库「+ 导入」 | 直接用原文件、**不复制**，大文件更快 |

---

## 二、素材库与拖拽分区
导入后视频出现在**素材库**。从素材库把条目**拖到下方某条轨道的某个时间点**即可生成片段。同一个素材可拖到多条轨道、多个位置。

**从资源管理器往窗口拖 mp4 时，按落点区域分流**（拖动时对应区域会高亮并给出提示）：
- 拖到**素材库** → **只入库**（之后你再从库里拖到轨道）。提示：「松开：导入到素材库」。
- 拖到**某条视频轨** → **入库 + 在该轨指针处直接添加片段**。提示：「松开：导入并添加到此轨道」。

---

## 三、多轨道与图层
- 默认有 **2 条视频轨**。
- 点右上「**+ 轨道**」可新增 **视频轨** 或 **文字轨**。
- **上层轨道盖住下层轨道**（轨道越靠上 = 图层越靠前）。上层若是缩小的小窗（画中画），就浮在下层画面之上；上层有空隙处会露出下层。
- 每条轨道左侧的**轨道头**可以：🔊 静音 / 拖动音量 · 👁 隐藏 · 🔒 锁定 · 🗑 删除。

---

## 四、画中画（缩放 + 定位）
1. 选中一个视频片段（时间轴上点它，或在预览里点它）。
2. 预览画面上出现**变换手柄**：拖**四角**等比缩放（缩小即变小窗）；拖**画面内部**移动位置。
3. 也可在右侧**属性面板**精确设置：位置、缩放、不透明度。
4. 把它放到上层轨道，就能做出**角标小窗 / 并排 / 画中画**效果。

---

## 五、文字标注
1. 点工具栏「**添加文字**」（放到文字轨上）。
2. 在预览里拖动定位、拖角缩放；**双击**文字可直接改文案。
3. 右侧属性面板可调：文案、字号、颜色、对齐、描边、半透明底框，以及**出现时间 / 消失时间**。
4. 文字始终显示在所有画面之上。
   - 💡 含 `¥` 等符号时，字体建议用「微软雅黑」（字符覆盖最全，避免方块）。

---

## 六、剪辑操作
| 操作 | 怎么做 |
|------|--------|
| **移动片段** | 直接拖动（可跨同类型轨道）。拖动时**磁吸**到其它片段边缘 / 播放头 / 起点；**按住 Alt 临时关磁吸** |
| **裁剪长度** | 拖动片段的**左右两端边缘**（不会超出原视频范围） |
| **分割** | 把播放头移到要切的位置，选中片段，按 **Ctrl+B**（或点「分割」） |
| **删除（留空隙）** | 选中片段按 **Delete** |
| **波纹删除（补缝）** | 选中片段按 **Backspace**：删除后**后面的片段自动前移补缝** |
| **复制 / 粘贴** | Ctrl+C 复制，Ctrl+V 粘到播放头处；Ctrl+D 原地复制一份 |
| **撤销 / 重做** | Ctrl+Z 撤销，Ctrl+Shift+Z（或 Ctrl+Y）重做 |

> 时间轴正上方有一排**就近工具条**（分割 / 删除 / 波纹删除 / 复制 / 撤销 / 重做），选中片段后高亮可点。

## 七、变速（慢放 / 快放）
单个视频片段可调速度，范围 **0.25×–4×**，声音**保持音调不变**。

**三种调速方式：**
1. 选中视频片段 → 右侧属性面板「**倍率**」滑块 / 数字框，直接输入精确值（如 `1.50×`）。
2. **按住 Shift 拖片段的右边缘或左边缘** —— **拉长 = 变慢，拉短 = 变快**。按住 Shift 把鼠标移到片段边缘时，指针会变成变速专用样式，提示「现在是变速操作」。
3. 变速后，片段块中间会显示当前倍率（如 `2.0×`）。

---

## 八、音频
- 导出时**所有轨道的声音会混合**在一起（多轨混音）。
- 每条视频轨可单独**静音**或**调音量**（轨道头）。
- 不想要任何声音：右侧「输出设置」取消勾选「**保留音轨**」。

---

## 九、播放与预览
- **空格**：播放 / 暂停
- 点击或拖动**刻度尺 / 播放头**：跳到任意时间
- **← / →**：后退 / 前进一帧；**Shift + ← / →**：±1 秒
- **Home / End**：跳到开头 / 结尾
- 时间轴缩放：底部 **− / +** 按钮，或键盘 **+ / −**

> ⚠️ **关于预览卡顿**：多条高分辨率视频轨同时播放时，浏览器内预览可能**掉帧或在片段切换处瞬间黑一下**——这是浏览器同时解码多个视频的固有限制，属正常现象。
> **导出不受影响**：最终成片由 ffmpeg 离线精确合成，画质与同步都是准确的。预览只是「大致看效果」，**以导出结果为准**。

## 十、完整快捷键表（剪映 / CapCut 风格）
> 软件内点工具栏「**⌨ 快捷键**」或按 **F1 / ?** 也可随时查看。

| 快捷键 | 功能 |
|--------|------|
| `空格` | 播放 / 暂停 |
| `Ctrl + B` | 在播放头处分割选中片段 |
| `Delete` | 删除选中片段（留空隙） |
| `Backspace` | 波纹删除（删除并使后面片段前移补缝） |
| `← / →` | 后退 / 前进一帧 |
| `Shift + ← / →` | 后退 / 前进 1 秒 |
| `↑ / ↓` | 选择上层 / 下层轨道的片段 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` 或 `Ctrl + Y` | 重做 |
| `Ctrl + C` / `Ctrl + V` | 复制片段 / 粘贴到播放头 |
| `Ctrl + D` | 原地复制一份片段 |
| `+` / `-` | 放大 / 缩小时间轴 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `Ctrl + S` | 打开导出 |
| `Esc` | 取消选中 |
| `按住 Shift 拖片段边缘` | 变速（拉长变慢 / 拉短变快） |
| `按住 Alt 拖片段` | 临时关闭磁吸对齐 |

> 注：分割 / 删除 / 复制等需要**先选中一个片段**。正在输入文字时，只有 `Ctrl+Z / 重做 / Esc` 生效，其它按键用于正常打字。

## 十一、导出
1. 右侧「**输出设置**」确认：分辨率预设（或手动填宽 / 高）、帧率 fps、画质 **CRF**（数字越小越清晰、文件越大；默认 18 已是高画质）、是否**保留音轨**。
2. 点右上「**导出**」（或 Ctrl+S）。
3. 选择保存位置和文件名。
4. 看进度条完成即可。

## 十二、常见问题 FAQ
- **点「导入」没反应 / 页面打不开**：后台服务没运行。重新双击 `启动.bat`，并保持黑色窗口开启。
- **双击 `启动.bat` 满屏「不是内部或外部命令」**：早期编码问题，已修复（启动脚本现为纯英文）。确认 `启动.bat` 与 `server.py` 在同一文件夹。
- **端口被占用**：会自动换端口，以黑窗里显示的网址为准。
- **拖拽导入很慢**：拖拽会复制整个文件，大视频请改用「选择导入」（用原文件、不复制）。
- **预览卡 / 切片段黑一下**：多视频预览的正常现象，导出是精确的，以成片为准。
- **中文 / 含空格的路径**：均支持。
- **某些字体显示方块**：换「微软雅黑」即可（覆盖字符最全）。
- **关掉浏览器标签了**：后台服务还在（黑窗没关），重新访问网址即可；编辑内容在网页里，**刷新或重开会丢失未导出的编辑**，重要的请及时导出。

## 给开发者
- **形态**：本地网页应用。后端 `server.py`（纯 Python 标准库 HTTP 服务，调用本机 ffmpeg/ffprobe）；前端 `static/`（纯原生 HTML/CSS/JS，无框架、无 CDN、可离线）。
- **运行**：双击 `启动.bat`，或命令行 `py -3 server.py`（默认 `127.0.0.1:8765`，端口占用自动 +1）。
- **目录结构**
  - `server.py` —— HTTP 服务与 API（静态资源、Range 视频流、文件对话框、拖拽上传、缩略图、导出任务与进度）
  - `ffmpeg_build.py` —— 由项目模型生成 ffmpeg 多轨合成滤镜图与参数（画中画 overlay + 文字 drawtext + 多音轨 amix + 变速 setpts/atempo）
  - `picker.py` —— 系统「打开 / 另存为」对话框（tkinter 子进程）
  - `static/` —— `index.html` / `style.css` / `app.js`（状态与模型）/ `timeline.js`（多轨时间轴）/ `player.js`（多视频同步预览）/ `overlay.js`（画中画与文字变换手柄）/ `shortcuts.js`（快捷键）/ `export.js`（导出）
  - `启动.bat` —— Windows 启动器
- **核心模型**：`project = { output, media[], tracks[] }`；轨道数组顺序即图层 z 序（末尾在最上）；片段几何用百分比（预览与导出同比）；视频片段时间轴长度 = `(out-in)/speed`。
- 详细数据模型 / API 契约 / ffmpeg 配方见 `_build/` 下的设计文档（contract / ffmpeg_recipe / engine / timeline 等）。

> 维护约定：**每次修改功能都要同步更新本 README**（README 是面向用户的唯一使用说明）。详见 `CLAUDE.md`。
