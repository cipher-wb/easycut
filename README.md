# 轻剪 EasyCut

> 一个**零安装、可离线**的本地视频剪辑小工具。用浏览器界面编辑，调用你电脑本机的 ffmpeg 导出。
> 适合给视频加中文说明、做画中画、变速、简单的多轨剪辑与拼接 —— 全部在本机运行，不上传、不联网。

本文档即**使用说明**。第一次用请从下面「快速开始」读起。

## 它能做什么
- **中文说明文字**：在画面任意位置加字，调字号 / 颜色 / 对齐 / 描边 / 半透明底框，并可设定**出现 / 消失时间**。
- **多轨道合成**：多条视频轨 + 文字轨，上层盖下层；可做**画中画 / 小窗 / 角标**。
- **变速**：单个片段慢放 / 快放（0.25×–4×），声音保持音调不变。
- **剪辑**：裁剪、分割、删除、波纹删除、复制 / 粘贴、拖动重排、跨轨移动、磁吸对齐。
- **拖拽导入**：从资源管理器把 mp4 拖进窗口；拖到素材库或直接拖到轨道。
- **工程管理**：把编辑状态保存为工程，下次打开继续；可建多个工程、另存为；素材丢失会标记离线并支持重新链接。
- **白天 / 夜间**：顶栏一键切换浅色 / 深色主题（暖色「Claude 风格」）。
- **实时预览** + **一键导出** 为新的 mp4（H.264 + AAC）。

## 运行环境
- **Windows 10/11**
- **Python 3**：建议用官网 <https://www.python.org> 的安装包（自带 `py` 启动器和 tkinter）。纯标准库、无需 pip。⚠️ 文件「打开 / 另存为」对话框依赖 **tkinter**——极简版 / 自定义安装若去掉了它，「选择导入」和「导出选保存位置」会点了没反应（重装官网版即可，默认就带）。
- **ffmpeg / ffprobe（必须先装）**：导出和解析视频全靠它。程序启动时会自动在 ① 命令行 PATH ② WinGet 默认安装目录 ③ `server.py` 同目录 三处查找；**三处都没有的话，界面能正常打开，但一导入或导出就失败**。安装方法见下。
- 一个现代浏览器（Edge / Chrome 等）

> 不需要联网、不需要 pip 依赖。前端是纯原生网页，后端是一个 Python 小服务。

### 安装 ffmpeg（只做一次，任选一种）
1. **WinGet（最推荐）**：打开 PowerShell 执行 `winget install Gyan.FFmpeg`，装完重新双击 `启动.bat`。
2. **手动加 PATH**：到 <https://www.gyan.dev/ffmpeg/builds/> 下载静态包，解压后把其中的 `bin` 目录加入系统环境变量 PATH。
3. **最省事**：把解压出的 `ffmpeg.exe` 和 `ffprobe.exe` 两个文件，直接复制到 `server.py` 所在的文件夹里即可（程序会自动找到，无需改 PATH）。

装好后在命令行执行 `ffmpeg -version` 和 `ffprobe -version`，能打印出版本号就成功了。

## 快速开始
1. **双击 `启动.bat`** —— 会弹出一个黑色命令行窗口，并自动打开浏览器进入编辑界面。
2. **使用期间请勿关闭那个黑色窗口**：它就是后台服务，关掉它工具就停了。
3. 用完后**直接关闭黑色窗口**即可停止。
4. 地址固定在 `http://127.0.0.1:8765`（端口被占用会自动换，以黑窗里显示的网址为准）。浏览器没自动开就手动访问该网址。
5. 启动后会弹出**工程面板**：点「＋ 新建工程」开始，或打开最近的工程继续上次的编辑。

> ⚠️ 如果点「导入」没反应、或页面打不开，多半是**后台服务没在运行**（黑窗被关了）。重新双击 `启动.bat` 即可。
> 💡 顶栏右侧「🌙 夜间 / ☀ 白天」可随时切换浅色 / 深色主题，偏好会被记住。

## 基本流程（最短路径）
1. **导入** mp4 → 进素材库
2. 从素材库**拖**一段到下方某条轨道
3. **编辑**：剪切、加文字、做画中画、调速度
4. **预览**：按空格播放
5. **导出**：点右上「导出」，选保存位置

---

## 一、导入视频（两种方式）
| 方式 | 操作 | 特点 |
|------|------|------|
| **拖拽导入** | 从资源管理器把 mp4 拖进窗口 | 方便；会把文件**复制**一份到工作目录，大文件稍慢 |
| **选择导入** | 点工具栏「导入 mp4」或素材库「+ 导入」 | 直接用原文件、**不复制**，大文件更快 |

---

## 二、素材库与拖拽分区
导入后视频出现在**素材库**。从素材库把条目**拖到下方某条轨道的某个时间点**即可生成片段。同一个素材可拖到多条轨道、多个位置。

**从资源管理器往窗口拖 mp4 时，按落点区域分流**（拖动时对应区域会高亮并给出提示）：
- 拖到**素材库** → **只入库**（之后你再从库里拖到轨道）。提示：「松开：导入到素材库」。
- 拖到**某条视频轨** → **入库 + 在该轨指针处直接添加片段**。提示：「松开：导入并添加到此轨道」。

---

## 三、多轨道与图层
- 默认有 **2 条视频轨**。
- 点右上「**+ 轨道**」可新增 **视频轨** 或 **文字轨**。
- **上层轨道盖住下层轨道**（轨道越靠上 = 图层越靠前）。上层若是缩小的小窗（画中画），就浮在下层画面之上；上层有空隙处会露出下层。
- 每条轨道左侧的**轨道头**可以：🔊 静音 / 拖动音量 · 👁 隐藏 · 🔒 锁定 · 🗑 删除。

---

## 四、画中画（缩放 + 定位）
1. 选中一个视频片段（时间轴上点它，或在预览里点它）。
2. 预览画面上出现**变换手柄**：拖**四角**等比缩放（缩小即变小窗）；拖**画面内部**移动位置。
3. 也可在右侧**属性面板**精确设置：位置、缩放、不透明度。
4. 把它放到上层轨道，就能做出**角标小窗 / 并排 / 画中画**效果。

---

## 五、文字标注
1. 点工具栏「**添加文字**」（放到文字轨上）。
2. 在预览里拖动定位、拖角缩放；**双击**文字可直接改文案。
3. 右侧属性面板可调：文案、字号、颜色、对齐、描边、半透明底框，以及**出现时间 / 消失时间**。
4. 文字始终显示在所有画面之上。
   - 💡 含 `¥` 等符号时，字体建议用「微软雅黑」（字符覆盖最全，避免方块）。

---

## 六、剪辑操作
| 操作 | 怎么做 |
|------|--------|
| **移动片段** | 直接拖动（可跨同类型轨道）。拖动时**磁吸**到其它片段边缘 / 播放头 / 起点；**按住 Alt 临时关磁吸** |
| **裁剪长度** | 拖动片段的**左右两端边缘**（不会超出原视频范围） |
| **分割** | 把播放头移到要切的位置，选中片段，按 **Ctrl+B**（或点「分割」） |
| **删除（留空隙）** | 选中片段按 **Delete** |
| **波纹删除（补缝）** | 选中片段按 **Backspace**：删除后**后面的片段自动前移补缝** |
| **复制 / 粘贴** | Ctrl+C 复制，Ctrl+V 粘到播放头处；Ctrl+D 原地复制一份 |
| **撤销 / 重做** | Ctrl+Z 撤销，Ctrl+Shift+Z（或 Ctrl+Y）重做 |

> 时间轴正上方有一排**就近工具条**（分割 / 删除 / 波纹删除 / 复制 / 撤销 / 重做），选中片段后高亮可点。

## 七、变速（慢放 / 快放）
单个视频片段可调速度，范围 **0.25×–4×**，声音**保持音调不变**。

**三种调速方式：**
1. 选中视频片段 → 右侧属性面板「**倍率**」滑块 / 数字框，直接输入精确值（如 `1.50×`）。
2. **按住 Shift 拖片段的右边缘或左边缘** —— **拉长 = 变慢，拉短 = 变快**。按住 Shift 把鼠标移到片段边缘时，指针会变成变速专用样式，提示「现在是变速操作」。
3. 变速后，片段块中间会显示当前倍率（如 `2.0×`）。

## 七·一、定格（冻结帧）
把视频里的**某一帧拉长成一段静止画面**，常用于「画面停住 + 加文字讲解给别人看」。

**怎么用：**
1. 选中一个视频片段，把**播放头**移到你想定格的那一帧。
2. 点工具栏「**❄ 定格 ▾**」（或按快捷键 **Shift+F** 直接「就地定格」），选一种：
   - **就地定格**：在播放头处把片段切开，中间插入一段静止画面（默认 **3 秒**），后面的内容自动往后让位（像剪映的「定格」）。
   - **生成独立静止片段**：单独生成一段这一帧的静止画面，你可以自由拖到任意位置。
3. 定格片段是**冷色块、带「❄ 定格」标记**。像普通片段一样**拖左右边缘可改显示时长**；右侧属性面板也能直接填「显示时长」和「定格的源帧时刻」。
4. 想在这段静止画面上加说明：用「**添加文字**」叠一条文字，时间段对齐这段定格即可。

> 定格段默认**静音**；导出时这一帧会被精确保持 N 秒。也可以对 AI 助手说「**把 XX 在第 10 秒定格 5 秒**」。

## 八、音频
- 导出时**所有轨道的声音会混合**在一起（多轨混音）。
- 每条视频轨可单独**静音**或**调音量**（轨道头）。
- 不想要任何声音：右侧「输出设置」取消勾选「**保留音轨**」。

## 九、播放与预览
- **空格**：播放 / 暂停
- 点击或拖动**刻度尺 / 播放头**：跳到任意时间
- **← / →**：后退 / 前进一帧；**Shift + ← / →**：±1 秒
- **Home / End**：跳到开头 / 结尾
- 时间轴缩放：底部 **− / +** 按钮，或键盘 **+ / −**

> ⚠️ **关于预览卡顿**：多条高分辨率视频轨同时播放时，浏览器内预览可能**掉帧或在片段切换处瞬间黑一下**——这是浏览器同时解码多个视频的固有限制，属正常现象。
> **导出不受影响**：最终成片由 ffmpeg 离线精确合成，画质与同步都是准确的。预览只是「大致看效果」，**以导出结果为准**。

## 九·一、工程（保存与打开）
把整个编辑状态（轨道、片段、文字、变速、输出设置等）保存为一个**工程**，下次打开继续。

- **保存**：`Ctrl + S`（或顶栏「💾 保存」）。第一次保存会让你起个工程名。
- **另存为**：`Ctrl + Shift + S` —— 复制出一个新工程，不影响原来的。
- **打开 / 新建 / 重命名 / 删除**：顶栏「🗂 工程」打开工程面板（启动时也会自动弹出）。
- 顶栏会显示当前工程名；有未保存改动时名字旁出现 **●**，关闭页面前会提示。
- 工程保存在程序目录的 `projects/` 下；拖拽导入的视频副本存在 `media_store/`（长期保管，不会丢）。

### 素材丢失了怎么办（重新链接）
工程只**记录**「选择导入」的视频原始路径。如果原文件被**移动 / 删除 / 改名**，打开工程时该素材会标记为**离线**：
- 素材库里该素材显示「离线」标记与「**重新链接**」按钮，时间轴上对应片段显示为红色占位 —— 但**所有编辑（裁剪/位置/文字/时长等）都保留**，不会丢。
- 顶部出现离线横幅。点素材的「重新链接」选择新文件即可恢复（像剪映 / Premiere 的 relink）。
- 若新文件比原来短，越界的片段会被自动裁剪并提示。

> 注：分割 / 删除 / 复制等需要**先选中一个片段**。正在输入文字时，只有 `Ctrl+Z / 重做 / Esc` 生效，其它按键用于正常打字。

## 十一、导出
1. 右侧「**输出设置**」确认：分辨率预设（或手动填宽 / 高）、帧率 fps、画质 **CRF**（数字越小越清晰、文件越大；默认 18 已是高画质）、是否**保留音轨**。
2. 点右上「**导出**」（或 Ctrl+E）。
3. 选择保存位置和文件名。
4. 看进度条完成即可。

## 十二· AI 剪辑助手（自然语言剪辑）

顶栏点「**✦ AI 助手**」会在最右侧展开一个聊天面板（可拖左边缘调宽、再点按钮收起）。你用**中文**说想怎么剪，AI 就直接帮你操作时间轴——**它执行的每一步都能用 `Ctrl+Z` 撤销**。

### 先做一次设置（填你自己的大模型）
首次打开会自动弹出「**⚙ 设置**」（也可随时点面板右上的 ⚙）：
- **接口协议**：`OpenAI 兼容`（DeepSeek / 通义千问 等，**推荐**）或 `Claude`。
- **服务地址 baseURL**：如 DeepSeek 填 `https://api.deepseek.com/v1`（OpenAI 兼容服务填到 `/v1` 即可，程序会自动补 `/chat/completions`）。
- **API Key**：你在模型服务商申请的密钥。
- **模型名称**：如 `deepseek-chat`。

> 🔒 **Key 安全**：配置只保存在本机的 `ai_config.json`，由本地后端代为调用模型（浏览器不直接联网，也就没有跨域问题）。这个文件**已被忽略，不会进入 git / 不会分享出去**。把工具发给同事时，对方填自己的 Key 即可。
> 📌 用 AI 时这台电脑需要能联网（其余剪辑功能仍可离线）。

### 怎么用（直接说人话）
在输入框里说，回车发送（Shift+Enter 换行）。例如：
- 「把素材库里**所有素材按顺序**放进时间轴」
- 「把名字**前缀是 “战斗”** 的几个视频依次放进来」（说"一起 / 同时播放"则会各占一条轨道叠放）
- 「把名为 **开场** 的视频放进时间轴，**减速到一半**」
- 「截取 **风景** 这个视频**中间三分之一到三分之二**的片段放进来」
- 「在 **开场** 这个视频**期间**，**左上角**加字幕：你好，欢迎」
- 「把刚加的片段**缩小到画面一半**、放到**右下角**」（画中画）
- 「把 **开场** 这个视频**在第 8 秒定格 4 秒**」（冻结帧）
- 「**导出**」（会打开导出窗口让你确认保存位置）

> 💡 对话内容**可复制**：直接选中文字复制，或把鼠标移到某条消息右上角点 **⎘** 一键复制整条。

### 它的工作方式（为什么稳）
- AI 不是"重写整个工程"，而是产出一串**结构化剪辑指令**，本地先**校验**（比如素材名对不上会被拦下），不合法会让模型**自动修正**后再执行——只有通过校验的才会落地。
- **找素材**忽略大小写和扩展名；说"名字为X"取最接近的一个，"前缀/包含X"可匹配多个；**拿不准时 AI 会反问你**，不会瞎猜。
- **编辑类指令直接执行**（撤销兜底）；**删除 / 删轨**会先让你点「执行」确认；**导出**走原来的导出窗口。
- 这套"指令"是可扩展的：以后想让 AI 会做的新操作，会持续往里加。

## 十三、常见问题 FAQ
- **点「导入」没反应 / 页面打不开**：后台服务没运行。重新双击 `启动.bat`，并保持黑色窗口开启。
- **导入视频后没反应 / 一点导出就失败（但页面能正常打开）**：八成是**没装 ffmpeg**。看启动黑窗里 `ffmpeg :` 和 `ffprobe :` 那两行——如果显示的只是 `ffmpeg`、`ffprobe`（而不是一段完整的 `.exe` 路径），就是没找到。按上面「安装 ffmpeg」装好后重开 `启动.bat`。
- **点「选择导入」或「导出」时不弹文件对话框**：你的 Python 缺少 tkinter，到官网重装 Python 3（默认选项即可，会自带）。
- **双击 `启动.bat` 满屏「不是内部或外部命令」**：早期编码问题，已修复（启动脚本现为纯英文）。确认 `启动.bat` 与 `server.py` 在同一文件夹。
- **端口被占用**：会自动换端口，以黑窗里显示的网址为准。
- **拖拽导入很慢**：拖拽会复制整个文件，大视频请改用「选择导入」（用原文件、不复制）。
- **预览卡 / 切片段黑一下**：多视频预览的正常现象，导出是精确的，以成片为准。
- **中文 / 含空格的路径**：均支持。
- **某些字体显示方块**：换「微软雅黑」即可（覆盖字符最全）。
- **关掉浏览器标签了**：后台服务还在（黑窗没关），重新访问网址即可；编辑内容在网页里，**刷新或重开会丢失未导出的编辑**，重要的请及时导出。
- **AI 助手报「尚未配置 / 无法连接」**：点面板右上 ⚙ 填好服务地址、API Key、模型名；确认这台电脑能联网、Key 有余额。地址要填到 `/v1`（OpenAI 兼容）。
- **AI 说「找不到素材」**：它只认素材库里**真实存在**的名字（看左侧素材库）。换个更准确的名字，或先把素材导入进来。
- **AI 做错了**：直接 `Ctrl+Z` 撤销即可；它的每条指令都进了撤销历史。

## 给开发者
- **形态**：本地网页应用。后端 `server.py`（纯 Python 标准库 HTTP 服务，调用本机 ffmpeg/ffprobe）；前端 `static/`（纯原生 HTML/CSS/JS，无框架、无 CDN、可离线）。
- **运行**：双击 `启动.bat`，或命令行 `py -3 server.py`（默认 `127.0.0.1:8765`，端口占用自动 +1）。
- **目录结构**
  - `server.py` —— HTTP 服务与 API（静态资源、Range 视频流、文件对话框、拖拽上传、缩略图、导出任务与进度、工程存取 `/api/projects/*`、重新链接 `/api/relink`、AI 代理 `/api/ai` 与配置 `/api/ai/config`）
  - `ffmpeg_build.py` —— 由项目模型生成 ffmpeg 多轨合成滤镜图与参数（画中画 overlay + 文字 drawtext + 多音轨 amix + 变速 setpts/atempo）
  - `picker.py` —— 系统「打开 / 另存为」对话框（tkinter 子进程）
  - `static/` —— `index.html` / `style.css`（Claude 暖色主题 + `:root[data-theme="dark"]` 夜间变体）/ `app.js`（状态与模型、工程序列化/加载/脏标记）/ `timeline.js`（多轨时间轴）/ `player.js`（多视频同步预览）/ `overlay.js`（画中画与文字变换手柄）/ `shortcuts.js`（快捷键）/ `projects.js`（工程面板/保存/打开/离线 relink）/ `export.js`（导出）/ `theme.js`（白天/夜间切换）/ `ai.js`（AI 剪辑助手：指令层 + 解析器 + 解释器 + 聊天面板）
  - `启动.bat` —— Windows 启动器
  - `projects/`、`media_store/` —— 运行时生成的用户数据（工程库 / 持久素材副本），已 .gitignore
- **核心模型**：`project = { output, media[], tracks[] }`；轨道数组顺序即图层 z 序（末尾在最上）；片段几何用百分比（预览与导出同比）；视频片段时间轴长度 = `(out-in)/speed`。工程文件 `projects/<id>/project.json` 即此模型 + 元信息；加载时按路径重新探测素材（在线/离线）。
- **UI 风格**：暖色「Claude 风格」，全部用 CSS 变量（`--bg/--panel/--accent/--text…`），深色主题由 `<html data-theme="dark">` 切换。新增 UI 一律复用这套变量，勿写死颜色。字体走系统（CSS 已有回退链），不依赖网络。
- 详细数据模型 / API 契约 / ffmpeg 配方等设计文档为开发者本地的内部资料（`_build/`，**未随本工具分发**）；如需可向作者索取。
